# 视频逐字稿与作品数据（抖音 / 小红书 / 快手 / B 站）

本技能自带脚本 `scripts/transcribe.py`（在本技能目录下）。它负责调用接口、断点续跑和整理输出。你只需要运行命令、读结果、交付。不要自己去打开视频网页，也不要下载视频。

## 1. 运行前检查

```bash
python <本技能目录>/scripts/transcribe.py --check
```

- 报 `缺少依赖`：运行 `python -m pip install -r <本技能目录>/requirements.txt`。
- `ready` 为 false：缺少 Key。请用户把 `transcript.env.example` 复制到 `~/.relie/transcript.env`（Windows 为 `C:\Users\<用户名>\.relie\transcript.env`），自己填入 TikHub 和阿里云百炼（华北2 北京地域）的 Key。如果用户直接在对话里给了 Key，可以替用户写进这个文件，但不要写进技能目录或代码仓库，也不要在回复里复述 Key。
- 只要数据、不要逐字稿时，只需要 TikHub Key。

## 2. 运行

在用户当前的工作目录运行，结果默认写到 `./relie-transcripts/`；也可以用 `--out` 指定目录。始终加 `--json`，这样结果打印在标准输出，进度日志在标准错误。

| 需求 | 命令 |
|---|---|
| 单条或几条 | `python <本技能目录>/scripts/transcribe.py "<链接或整段分享文案>" "<链接2>" --json` |
| 链接清单文件 | `python <本技能目录>/scripts/transcribe.py --file links.txt --json`（.txt 每行一条，或 .csv） |
| 先试跑几条 | 加 `--limit 5` |
| 只要数据，不转写 | 加 `--stats-only` |
| 要评论内容 | 加 `--comments 20`（前 20 条） |
| 要抖音播放量 | 加 `--douyin-plays` |
| 重试失败的 | `--retry-failed`（可以带原来的链接或文件，也可以不带，不带就重试全部） |
| 中断后继续 | 重新运行同一条命令；已完成的会跳过，不会重复扣费 |

批量任务可能要跑几十分钟。命令行工具有超时限制的话，放到后台运行，中断后重新运行同一条命令即可续上。

## 3. 费用规则（必须遵守）

两个接口都按次或按时长计费：TikHub 按调用次数，百炼按音频时长。

TikHub 单价（2026-10 实测，以控制台为准）：抖音、快手、B 站每次调用 $0.001；小红书每次 $0.01。一条视频通常调用 1 次（B 站转写多 1 次），所以一般是 $0.001～0.01 每条。

- 点赞、评论数、收藏、分享会随解析一起返回，不额外计费。B 站和快手的播放量也一样。
- **额外计费的开关默认不开**：`--comments`（每页约 20 条，每页计费一次）、`--douyin-plays`（每条多一次调用）。只有用户明确要这些数据时才加。
- 一次处理超过 20 条链接，或者对多条链接开启 `--comments`，先告诉用户条数和会产生费用，得到同意再跑。首次大批量建议先 `--limit 5` 试跑。
- 小红书无效链接也会扣费，不要反复重试明显无效的小红书链接。

## 4. 交付

读 `--json` 输出的 `items`，每条有 `status`、各项数据和 `md_path`。逐字稿全文在 `md_path` 指向的 Markdown 文件里，需要时再读取。

- **单条或少量**：给出标题、作者、发布时间、互动数据（拿不到的写"—"，并说明原因，例如小红书不公开播放量、抖音播放量需要 `--douyin-plays`），再附上逐字稿。逐字稿很长时，先给文件路径和开头一段，问用户是否要全文。
- **批量**：报告成功和失败的条数，以及汇总表 `summary.xlsx` 和 `transcripts/` 目录的路径。失败的条目按错误原因分类说明。
- 逐字稿是百炼语音识别的结果，没有经过人工校对，专有名词可能识别错，交付时要注明。不要擅自润色或补写。
- `status` 为 `failed` 时，如实说明 `error` 里的原因。不要拿视频文案或标题冒充逐字稿。逐字稿为空，说明"未识别到人声"（例如纯音乐视频）。
- 互动数据是获取那一刻的快照（见 `stats_at`），交付时注明获取时间。

## 5. 常见失败

| 错误信息 | 处理 |
|---|---|
| 作品不可用（已删除/私密）、没有找到视频地址（图文） | 跳过，告诉用户 |
| 视频地址过期或有防盗链 | `--retry-failed`，会自动改为先下载再上传 |
| 转写任务已失效/超时 | `--retry-failed` |
| HTTP 401/403（TikHub 或百炼） | Key 无效、余额不足或百炼地域不对，请用户检查控制台 |
| 专有名词识别错 | 建议用户在百炼控制台建热词表，把 ID 填到配置的 `HOTWORDS_VOCAB_ID` |

只处理用户指定的作品，不扩展成整个账号的采集。逐字稿和评论供用户个人研究使用；用户要公开转载时，提醒注意原作者版权。
