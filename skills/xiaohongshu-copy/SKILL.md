# 小红书笔记文案采集

先确定用户要处理单篇笔记还是博主当前公开可见的全部笔记。通过正常页面打开分享短链，核对笔记 ID、作者和最终来源链接；批量整理时按笔记 ID 去重，浏览至当前可见目录末尾，并记录采集时间与可见数量。不要把本次未见的旧笔记直接判定为删除，也不要声称覆盖隐藏或已删除内容。

## 区分文案来源

- **标题与正文**：保留原有段落、话题标签和可见发布时间，不用图片文字代替正文。
- **图片文字**：按图片顺序单独记录。遇到遮挡、字迹不清或识别不确定的部分，标注疑点，不猜补。
- **视频口播**：只有用户提供逐字稿，或经用户已授权的转写工具取得并核对源笔记后，才标记为“已获取”。发布正文、字幕片段和 AI 总结不自动等同于完整口播；处理中、截断或来源不符要分别标明。
- **互动与评论**：记录页面可见的点赞、收藏、评论等数据及采集时间；约数保留约数。评论只作为可见样本，保留实际显示的点赞数，不宣称全量最高赞。

每篇笔记的交付记录至少能看出来源链接、笔记 ID、作者、标题、正文、图片文字或口播的各自状态、公开数据及采集时间。缺失字段留空并解释原因；更新已有记录时保留用户自己的批注与修改。

只使用正常可见页面或已授权的能力。遇到登录、验证码、访问限制或付费门槛，暂停受阻步骤并报告，不绕过限制或收集账号凭证。除非用户另有要求，不下载图片或视频文件。
