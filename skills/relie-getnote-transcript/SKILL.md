# Get 笔记视频逐字稿

接收用户给的视频分享链接或包含链接的分享文字。每条链接对应一条视频；先识别抖音、小红书或 B 站，保留原始链接。只有主页、合集或搜索页而没有具体视频时，先定位用户指定的视频，不自行扩展到全部作品。

## 获取

1. 使用用户已授权、已登录的 Get 笔记正常页面。通过「添加／粘贴链接」导入视频分享链接；如果分享文字包含额外口令，确认 Get 笔记识别的是其中的视频 URL。核对导入结果的来源、标题或作者，避免拿错视频。
2. 等待该条链接处理完成，再打开笔记中的「链接原文」「原文逐字稿」或同等入口，读取完整可见文本。长视频可能需要较长处理时间；仍在处理中就报告状态，不把等待中的笔记说成已取得逐字稿。
3. 确认拿到的是视频口播转写，而不是发布配文、字幕片段、图片文字或 AI 摘要。检查开头、结尾是否明显缺失或截断；能从源视频核对时，抽查关键句与内容归属。无法逐句校对时注明「Get 笔记转写，未人工逐句校对」，不要宣称百分之百准确。

## 交付

直接给出视频来源链接和完整可取得的逐字稿，尽量保留原有段落与措辞。只做必要的排版，不擅自润色、删节或补写。若用户要求保存文件，再另存为 `.txt` 或其指定格式。

如果 Get 笔记只给出部分原文，标记「疑似不完整」并给出已取得部分；如果只得到总结、链接不受支持或导入失败，明确说「逐字稿未取得」，不要拿总结冒充。遇登录、验证码、访问限制、额度或付费门槛，暂停相应步骤并说明需要用户处理的事项，不绕过限制或购买服务。只处理用户有权访问的内容，不把第三方逐字稿未经许可公开再分发，也不要下载视频文件。

三平台链接导入方式见 [Get 笔记官方说明](https://doc.biji.com/docs/GfPqwZfDRibB44kXvmvcQBRDngd)。支持导入不等于保证每条视频都能成功生成完整逐字稿。
