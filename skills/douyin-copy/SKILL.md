# 抖音作品文案采集

按用户指定的范围整理作品：单条链接只处理该条；博主主页需要覆盖当前公开可见的作品目录，并以作品 ID 去重。短链接通过正常页面打开后，以最终作品链接为准。先核对作品所属作者，避免把转发、合集或搜索结果混入目标博主。

## 采集与核验

1. 记录作品链接、作品 ID、作者、可见发布时间和采集时间。若要求整理整个主页，浏览至当前可见目录末尾，分别记录主页标注数量和实际看到的作品链接数量；两者不一致时保留差异。旧记录本次未出现只标记为“本次未见”，不要推断已删除。
2. 分开保存**发布配文**和**口播逐字稿**。配文、话题标签、封面文字或 AI 总结都不能充当口播。图文作品还要把配文与图片内文字分开。
3. 口播只从用户提供的逐字稿，或用户已授权使用的转写／笔记服务取得。核对转写结果对应的原视频，检查开头、结尾及明显截断；未完成的导入标记“处理中”，无法核实完整性的标记“待核对”，不能写成“已获取全文”。
4. 如页面可见，记录点赞、评论、收藏、分享及其显示方式（精确数或约数），并注明采集时间。评论只采集适量可见文字样本及页面实际显示的点赞数，不称其为全站最高赞或全量评论。

输出应让每条记录都能追溯：来源链接、作者、发布时间、配文、口播及其来源与状态、公开数据、评论样本和采集时间。无法取得的字段留空并说明原因，不根据标题或片段补写原文，也不把约数改写成精确值。更新已有资料时按作品 ID 合并，保留用户原有笔记和修订。

只使用正常可见页面或已授权的能力。遇到登录、验证码、访问限制或付费门槛，暂停受阻步骤并报告；不要绕过限制、索取或保存账号凭证。除非用户另有要求，不下载视频文件。
