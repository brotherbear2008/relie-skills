# Get 笔记原文采集

使用用户已授权、已登录的 Get 笔记正常界面。输入可以是单条作品链接或链接清单；如果只有作者主页，先取得具体作品链接，再逐条处理。保留原始链接，以作品链接或作品 ID 去重。

1. 在 Get 笔记中使用「粘贴链接」导入作品，打开对应条目的「链接原文」。先核对条目指向的源作品，再复制界面实际给出的文本。导入仍在处理时，记录为「处理中」，不要填入猜测的文案。
2. 区分**发布配文、图片内文字、视频口播原文和 AI 总结**。Get 笔记的「链接原文」也应标明为平台提取结果；未经源视频核对，不宣称逐字准确。不要用标题、配文或 AI 总结补造缺失的口播。
3. 核对来源链接、作者及可见标题或开头，并检查原文首尾与段落是否明显缺失、混入其他作品或截断。遇到疑似截断，保留已取得的原文并标注「疑似不完整」及原因；只在来源出现新内容或用户要求时重试。
4. 交付时按作品记录：原始链接、作者、标题或主题、发布配文（如取得）、链接原文、取得时间、来源和状态。保留原文段落与措辞；另写摘要或分析时，与原文分开。批量处理时说明已发现、处理中、已取得、疑似不完整和未取得的数量。

遇到登录、验证码、访问限制、额度或付费门槛，记录受阻作品并暂停该路径，不绕过、不代替用户购买。保留已有原文和用户修订，不为凑完整率覆盖或编造内容。
